Geospatial technology and GIS frameworks enable analysts and software developers to capture, store, manipulate, analyze, and visualize spatial vector and raster datasets. This list is intended for GIS specialists, spatial data engineers, cartographers, remote sensing analysts, and location-intelligence developers.

## Desktop & Server GIS Systems

Open-source desktop applications and spatial web servers for mapping, spatial analysis, and publishing OGC-compliant web services.

- [QGIS](https://github.com/qgis/QGIS) — User-friendly, open-source Geographic Information System for viewing, editing, analyzing, and composing spatial data.
- [GeoServer](https://github.com/geoserver/geoserver) — Open-source server written in Java that allows users to share, process, and edit geospatial data adhering to OGC standards.
- [GRASS GIS](https://github.com/OSGeo/grass) — Powerful geospatial data management, vector/raster processing, spatial modeling, and visualization engine.
- [MapServer](https://github.com/MapServer/MapServer) — Open-source development environment for building spatially enabled internet applications and web mapping services.

## Spatial Databases & Extensions

Relational and NoSQL database engines optimized for storing, indexing, and querying spatial geometries and raster layers.

- [PostGIS](https://github.com/postgis/postgis) — Spatial database extender for PostgreSQL relational database that adds support for geographic objects and spatial SQL queries.
- [SpatiaLite](https://www.gaia-gis.it/fossil/libspatialite/index) — Spatial extension to SQLite providing light, file-based spatial database capabilities conforming to OGC specifications.
- [DuckDB Spatial Extension](https://github.com/duckdb/duckdb_spatial) — Geospatial extension for DuckDB enabling fast column-oriented spatial queries and geometry processing.
- [H3](https://github.com/uber/h3) — Hexagonal hierarchical spatial index system developed by Uber for grid-based spatial partitioning and indexing.

## Geospatial Data Libraries

Core libraries and programming toolkits for spatial operations, coordinate transformations, and vector/raster parsing.

### Python Spatial Ecosystem

- [GeoPandas](https://github.com/geopandas/geopandas) — Open-source project extending pandas data structures to enable spatial operations on geometric types.
- [Shapely](https://github.com/shapely/shapely) — Manipulation and analysis of planar geometric objects based on the GEOS C++ library.
- [Rasterio](https://github.com/rasterio/rasterio) — Fast spatial raster input/output library for accessing multispectral satellite and elevation datasets.
- [Fiona](https://github.com/Toblerity/Fiona) — Python API for reading and writing vector geospatial data files based on OGR capabilities.

### C/C++ & Core Processing Engines

- [GDAL/OGR](https://github.com/OSGeo/gdal) — Translator library for raster and vector geospatial data formats that powers most open-source GIS platforms.
- [PROJ](https://github.com/OSGeo/PROJ) — Generic coordinate transformation software that transforms geospatial coordinates from one coordinate reference system to another.
- [GEOS](https://github.com/libgeos/geos) — C++ port of the Java Topology Suite (JTS) providing spatial predicate and topology functions.

## Web Mapping & Visualization

Client-side JavaScript frameworks and rendering engines for displaying interactive maps and geospatial layers in web applications.

- [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js) — Open-source TypeScript library for publishing vector maps on the web using WebGL.
- [Leaflet](https://github.com/Leaflet/Leaflet) — Leading open-source JavaScript library for mobile-friendly interactive maps.
- [OpenLayers](https://github.com/openlayers/openlayers) — High-performance feature-packed web mapping library for rendering raster and vector maps.
- [turf.js](https://github.com/Turfjs/turf) — Advanced geospatial analysis engine written in JavaScript for performing spatial operations client-side.
